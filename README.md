# JSteamWorks

Java bindings for Valve's [Steamworks SDK](https://partner.steamgames.com/doc/sdk), built entirely on [Project Panama](https://openjdk.org/projects/panama/).

JSteamWorks provides a modern, type-safe Java interface to the native Steamworks API without relying on JNI or manually written native glue code.

> Project is in early development. API and functionality are subject to change.
